# PackageSources

Hier entstehen die SDK-Szeneriequellen und eigenen 3D-Modelle.

`model_concepts/` wird durch `python tools/generate_models.py` erzeugt. Diese Modelle sind vorläufig und nicht automatisch MSFS-kompatibel. Die endgültigen Modelle werden mit dem aktuellen MSFS-2024-SDK-Exporter gebaut.
